# 🧠 React Quiz App

An interactive and responsive Quiz application built with **React** and **Vite**. Features custom timed questions, dynamic option shuffling, real-time visual answer feedback, and a final score summary.

---

## ✨ Features

- ⏱️ **Question Timer:** Automatic countdown per question with dynamic state transitions using React hooks (`useState`, `useEffect`).
- 🔀 **Shuffled Answers:** Answer options are randomly shuffled on initial render using `useRef` to ensure a unique experience every time.
- 🎨 **Instant Visual Feedback:** Color-coded button states (*Selected*, *Correct*, *Wrong*) that update seamlessly during gameplay.
- 📊 **Final Score Summary:** Calculates and displays your final score out of the total number of questions upon quiz completion.
- 📱 **Responsive Design:** Optimized layout for smooth play on desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Framework:** React 18+
- **Build Tool:** Vite
- **Language:** JavaScript (ES6+)
- **Styling:** CSS3
